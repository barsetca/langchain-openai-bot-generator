# Локальный AI-агент (LangChain + OpenAI)

Агент запускается из терминала, понимает задачи на естественном языке и выбирает инструменты: погода, курс криптовалют, поиск в интернете, HTTP-запросы, файлы, терминал, память, **генерация QR-кодов**, **калькулятор сложных выражений**.

## Структура

```
agent/
  ├── agent.py         # логика агента (LLM + инструменты)
  ├── tools.py         # инструменты (погода, крипта, поиск, HTTP, файлы, терминал, память, QR, калькулятор)
  ├── run.py           # CLI-интерфейс
  ├── memory.json      # долговременная память (история диалога)
  ├── output/qr/       # созданные QR-коды (по умолчанию)
docs/
  └── agent.log        # логи шагов работы агента
  └── README_AGENT.md
```

## Зависимости

Для агента нужны: `openai`, `requests`, `ddgs`, `python-dotenv`, `qrcode[pil]`, `sympy`, LangChain. Установка (из корня проекта):

```bash
pip install -r requirements.txt
```

## Переменные окружения

В корне проекта в `.env` должны быть:

- `OPENAI_API_KEY` — ключ OpenAI
- `OPENAI_MODEL` — модель (например `gpt-4.1` или `gpt-4o-mini`)

Остальные опционально: `OPENAI_TEMPERATURE`, `OPENAI_MAX_TOKENS`.

## Запуск

**Из каталога `agent/`:**

```bash
cd agent
python run.py
```

**Из корня проекта:**

```bash
python agent/run.py
```

или

```bash
python -m agent.run
```

В диалоговом режиме вводите запросы. Пустая строка или Ctrl+D — выход.

**Примеры запросов:**

- Погода и крипта: «Какая погода в Москве?», «Сколько стоит Bitcoin в рублях?»
- Поиск: «Найди в интернете последние новости про ИИ»
- **QR-код:** «Сгенерируй QR-код для ссылки https://example.com», «Сделай QR-код с текстом: Мой Wi-Fi пароль 12345»
- **Вычисления:** «Посчитай (2^5 + 3*sqrt(7)) / sin(0.5)», «Реши выражение: ln(2) + cos(0)»

## Логи

Все шаги работы пишутся в `docs/agent.log` (логи не выводятся в консоль диалога).

## Память

История диалога сохраняется в `agent/memory.json` и подгружается при следующем запуске для контекста.

## QR-коды

Созданные QR-коды сохраняются в `agent/output/qr/`. Имя файла можно задать в запросе или будет автоматическое `qr_<timestamp>.png`. В ответе агент указывает полный путь к файлу.
